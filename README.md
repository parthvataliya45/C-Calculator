# C-Calculator
A simple calculator program written in C language.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Language
- C

## How to Run
1. Compile calculator.c
2. Run the program
3. Select an operation
4. Enter two numbers

## Sample Output

Enter first number: 10

Enter second number: 5

1. Addition
2. Subtraction
3. Multiplication
4. Division

Choose an operation: 1

Result = 15.00
