# C-Calculator
A simple calculator program written in C language.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Division by zero handling

## Language
- C

## How to Run
1. Compile calculator.c
2. Run the program
3. Select an operation
4. Enter two numbers

## Sample output
Enter first number: 10
Enter Second number: 20

1.Addition
2.Substraction
3.Multiplication
4.Division

Choose an operation: 1

Result = 30.00
